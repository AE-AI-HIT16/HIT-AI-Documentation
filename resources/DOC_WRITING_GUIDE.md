# Documentation Writing Guide

Hướng dẫn tổ chức và viết tài liệu cho HIT-AI-Documentation (AI Engineer & Data Engineer).

## 1. Cấu trúc thư mục

### 1.1 Cấp 1 — Section / Track

- **Quy ước:** `NN-<Level>: <Tên ngắn>` hoặc `NN-<Tên section>`
- **Ví dụ:**
  - `01-Foundations` hoặc `01-Basic: AI Fundamentals`
  - `02-Advanced` hoặc `02-Advanced: Data Engineering`
  - `03-Basic: FastAPI`
  - `04-Masterclass` hoặc `04-Comprehensive: Data Engineering Masterclass`

### 1.2 Cấp 2 — Module

- **Quy ước:** `NN-<slug-module>` (slug dùng dấu gạch ngang)
- **Ví dụ:** `01-rag-and-optimization`, `02-spark-advanced`, `01. Knowledge`

### 1.3 Cấp 3 — Nhóm bài

- **Quy ước:** Thống nhất dùng **`01. Knowledge`** cho tất cả section (AI Engineer và Data Engineer).
- Không dùng tên riêng như `01. Core Concept of Data Engineer`.

### 1.4 File bài viết

- **Định dạng:** Ưu tiên **`.mdx`** (hỗ trợ JSX/component). Chỉ dùng `.md` khi không cần component.
- **Đặt tên:** `NN-<slug-bài>.mdx` (ví dụ: `01-introduction-to-ai.mdx`, `02-data-types.mdx`).

## 2. Frontmatter (DOC_STANDARD)

Mọi file doc phải có frontmatter YAML ở đầu file.

### 2.1 Bắt buộc

| Trường       | Mô tả                          | Ví dụ                    |
|-------------|---------------------------------|--------------------------|
| `title`     | Tiêu đề hiển thị (không có số) | `Data Engineering Core`  |
| `description` | Mô tả ngắn cho SEO/search    | `Core concepts of Data Engineering` |
| `authors`   | Mảng tên tác giả               | `["TienPD"]` hoặc `["HoangNH", "TienPD"]` |

### 2.2 Nên có

| Trường  | Mô tả                    | Ví dụ |
|---------|--------------------------|--------|
| `tags`  | Mảng tag để tìm kiếm     | `["Spark", "Data Lake", "Architecture"]` |
| `sidebar_position` | Thứ tự trong sidebar (số) | `1` |

### 2.3 Tránh

- **Không** thêm số vào `title` (sai: `01. Data Engineering Core` → đúng: `Data Engineering Core`).
- **Tránh** `slug` tùy chỉnh trừ khi cần redirect; để Docusaurus auto-generate từ đường dẫn file.
- **authors:** luôn dùng mảng string `["TienPD"]`, không dùng `[TienPD]` (không quote).

### 2.4 Ví dụ frontmatter đúng

```yaml
---
title: "Introduction to AI & Generative AI"
description: "Understanding the basics of Artificial Intelligence and the rise of Generative AI"
tags: ["AI", "Generative AI", "LLM", "Fundamentals"]
authors: ["HoangNH"]
---
```

```yaml
---
title: Data Engineering Core
description: Core concepts of Data Engineering, including Data Architecture, Data Lake, Warehouse, Lakehouse.
tags: ["Data Engineering", "Architecture", "Data Lake"]
authors: ["TienPD"]
sidebar_position: 1
---
```

## 3. Category (sidebar)

Mỗi thư mục section/module cần file **`_category_.json`** để cấu hình sidebar.

### 3.1 Cấu trúc

```json
{
  "label": "Tên hiển thị trong sidebar",
  "position": 1,
  "link": {
    "type": "generated-index",
    "description": "Mô tả ngắn cho trang index"
  }
}
```

### 3.2 Ví dụ

- **Section Foundations:**  
  `"label": "Data Engineering Foundations"`, `"description": "Introduction to Data Engineering"`

- **Section Advanced:**  
  `"label": "Advanced Data Engineering"`, `"description": "Spark advanced, DataOps, Observability"
