# Data Quality & Governance

Ensuring data is accurate, complete, and reliable is critical.

## Data Governance Tools
*   **DataHub:** An open-source metadata platform for the modern data stack. It provides data discovery, observability, and lineage.
*   **Data Contract:** An agreement between data producers and consumers on the schema, semantics, and SLAs of the data.

## Data Quality Validation

### 1. Great Expectations (GX)
The leading tool for validating, documenting, and profiling your data.

**Key Concept:** "Expectations" are assertions about your data (e.g., `expect_column_values_to_be_unique`).

**Implementation Guide:**

**Setup:**
```bash
pip install great_expectations
great_expectations init
```

**Python Script to Validate Data:**

```python
import great_expectations as gx

# 1. Get Context
context = gx.get_context()

# 2. Connect to Data
validator = context.sources.pandas_default.read_csv("data/customer_data.csv")

# 3. Define Expectations
validator.expect_column_values_to_be_unique("customer_id")
validator.expect_column_values_to_not_be_null("email")
validator.expect_column_values_to_be_between(
    "age", min_value=18, max_value=120
)
validator.expect_column_values_to_be_in_set(
    "subscription_type", ["free", "premium", "enterprise"]
)

# 4. Save and Run Checkpoint
validator.save_expectation_suite(discard_failed_expectations=False)
checkpoint = context.add_or_update_checkpoint(
    name="my_checkpoint",
    validator=validator,
)
checkpoint_result = checkpoint.run()

# 5. View Results
context.open_data_docs()
```

### 2. Deequ (Amazon)
A library built on top of Apache Spark for defining "unit tests for data".

**Implementation Guide (PyDeequ):**

```python
from pyspark.sql import SparkSession
import pydeequ
from pydeequ.checks import *
from pydeequ.verification import *

spark = SparkSession.builder \
    .config("spark.jars.packages", pydeequ.deequ_maven_coord) \
    .config("spark.jars.excludes", pydeequ.f2j_maven_coord) \
    .getOrCreate()

df = spark.read.json("data/transactions.json")

check = Check(spark, CheckLevel.Warning, "Data Validation")

checkResult = VerificationSuite(spark) \
    .onData(df) \
    .addCheck(
        check.hasSize(lambda x: x >= 1000) \
        .isComplete("transaction_id") \
        .isUnique("transaction_id") \
        .isNonNegative("amount")
    ) \
    .run()

checkResult_df = VerificationResult.checkResultsAsDataFrame(spark, checkResult)
checkResult_df.show()
```
