# MLOps

MLOps (Machine Learning Operations) is the practice of deploying and maintaining machine learning models in production reliably and efficiently.

## What is MLOps?

MLOps combines ML, DevOps, and Data Engineering practices to:

- **Automate** ML workflows
- **Version** models, data, and code
- **Monitor** model performance
- **Reproduce** experiments
- **Deploy** models quickly and safely

## MLOps Lifecycle

```
Data → Training → Validation → Deployment → Monitoring → Retraining
  ↑                                                              ↓
  └────────────────────── Feedback Loop ───────────────────────┘
```

## Key Components

### 1. Experiment Tracking

Track experiments, parameters, and metrics:

```python
import mlflow

mlflow.set_experiment("my-experiment")

with mlflow.start_run():
    mlflow.log_param("learning_rate", 0.01)
    mlflow.log_param("epochs", 100)
    
    # Train model
    model = train_model()
    
    mlflow.log_metric("accuracy", 0.95)
    mlflow.sklearn.log_model(model, "model")
```

### 2. Model Registry

Centralized model storage and versioning:

```python
# Register model
mlflow.register_model(
    "runs:/<run-id>/model",
    "production-model"
)

# Load model
model = mlflow.pyfunc.load_model(
    "models:/production-model/1"
)
```

### 3. Model Deployment

Deploy models to various environments:

```python
# Deploy to local server
mlflow models serve -m "models:/production-model/1" -p 5000

# Deploy to cloud
mlflow deployments create \
  --target sagemaker \
  --name production-model \
  -m "models:/production-model/1"
```

### 4. Monitoring

Monitor model performance and data drift:

```python
import evidently

# Data drift detection
data_drift_report = evidently.Report(metrics=[
    evidently.metrics.DataDriftPreset()
])
data_drift_report.run(
    reference_data=reference_df,
    current_data=current_df
)
```

## CI/CD for ML

### GitHub Actions Example

```yaml
name: ML Pipeline

on:
  push:
    branches: [ main ]

jobs:
  train:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.9'
      - name: Install dependencies
        run: pip install -r requirements.txt
      - name: Train model
        run: python train.py
      - name: Run tests
        run: pytest tests/
      - name: Deploy model
        run: python deploy.py
```

## Best Practices

1. **Version Everything**: Code, data, models, and configurations
2. **Automate Workflows**: Use CI/CD pipelines
3. **Monitor Continuously**: Track model performance and data quality
4. **Test Thoroughly**: Unit tests, integration tests, model tests
5. **Document Clearly**: Document experiments and decisions
6. **Security**: Secure your ML pipelines and models
