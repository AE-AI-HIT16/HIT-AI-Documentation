# Introduction

Welcome to the Docusaurus documentation template!

This is a documentation site template based on Docusaurus, including custom theme components and configurations.

## Getting Started

1. Edit `docusaurus.config.js` to configure your site information
2. Add your documentation in the `docs/` directory
3. Configure the sidebar structure in `sidebars.js`
4. Run `npm start` or `yarn start` to start the development server

## Features

- 📝 Markdown/MDX based documentation writing
- 🎨 Custom theme components
- 🔍 Built-in search functionality
- 📱 Responsive design
- 🌙 Dark mode support
