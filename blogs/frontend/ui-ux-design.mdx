# UI/UX Design

User Interface (UI) and User Experience (UX) design are crucial for creating successful web applications.

## Design Principles

### 1. User-Centered Design

- **Understand Users**: Research user needs and behaviors
- **Accessibility**: Design for all users, including those with disabilities
- **Usability**: Make interfaces intuitive and easy to use
- **Feedback**: Provide clear feedback for user actions

### 2. Visual Hierarchy

- **Contrast**: Use contrast to guide attention
- **Spacing**: Use whitespace effectively
- **Typography**: Choose readable fonts and sizes
- **Color**: Use color strategically, not decoratively

### 3. Consistency

- **Design System**: Use consistent components and patterns
- **Navigation**: Maintain consistent navigation structure
- **Language**: Use consistent terminology
- **Interactions**: Keep interaction patterns consistent

## Responsive Design

### Mobile-First Approach

```css
/* Mobile styles (default) */
.container {
  padding: 1rem;
  font-size: 14px;
}

/* Tablet styles */
@media (min-width: 768px) {
  .container {
    padding: 2rem;
    font-size: 16px;
  }
}

/* Desktop styles */
@media (min-width: 1024px) {
  .container {
    padding: 3rem;
    font-size: 18px;
    max-width: 1200px;
    margin: 0 auto;
  }
}
```

### Breakpoints

## Accessibility (a11y)

### WCAG Guidelines

- **Perceivable**: Information must be presentable to users
- **Operable**: Interface components must be operable
- **Understandable**: Information must be understandable
- **Robust**: Content must be robust enough for assistive technologies

### Implementation

```jsx
// Semantic HTML
<button aria-label="Close dialog">
  <CloseIcon />
</button>

// Keyboard navigation
<div
  role="button"
  tabIndex={0}
  onKeyDown={(e) => {
    if (e.key === 'Enter' || e.key === ' ') {
      handleClick();
    }
  }}
>
  Click me
</div>

// ARIA attributes
<div
  role="alert"
  aria-live="polite"
  aria-atomic="true"
>
  {errorMessage}
</div>
```

## Design Patterns

### Common UI Patterns

- **Navigation**: Top nav, sidebar, breadcrumbs
- **Forms**: Input validation, error states
- **Modals**: Dialog boxes, confirmations
- **Cards**: Content containers
- **Lists**: Data display, tables
- **Search**: Filters, sorting

### Example: Card Component

```jsx
function Card({ title, description, image, onClick }) {
  return (
    <div
      className="card"
      role="article"
      onClick={onClick}
      onKeyDown={(e) => {
        if (e.key === 'Enter') onClick();
      }}
      tabIndex={0}
    >
      {image && (
        <img
          src={image}
          alt={title}
          className="card-image"
        />
      )}
      <div className="card-content">
        <h3 className="card-title">{title}</h3>
        <p className="card-description">{description}</p>
      </div>
    </div>
  );
}
```

## User Research

### Methods

- **Interviews**: One-on-one conversations
- **Surveys**: Quantitative data collection
- **Usability Testing**: Observe users using the product
- **Analytics**: Track user behavior
- **A/B Testing**: Compare design variations

## Best Practices

1. **Start with User Needs**: Research before designing
2. **Iterate**: Design is an iterative process
3. **Test Early**: Test with real users
4. **Accessibility First**: Build accessible from the start
5. **Performance**: Fast loading times improve UX
6. **Mobile First**: Design for mobile, enhance for desktop
