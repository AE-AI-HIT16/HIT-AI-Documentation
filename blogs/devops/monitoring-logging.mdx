# Monitoring & Logging

Effective monitoring and logging are essential for maintaining healthy production systems.

## Monitoring Types

### 1. Infrastructure Monitoring

Monitor server resources:

```yaml
# Prometheus metrics
- name: cpu_usage
  type: gauge
  value: 75.5

- name: memory_usage
  type: gauge
  value: 60.2

- name: disk_usage
  type: gauge
  value: 45.8
```

### 2. Application Monitoring

Monitor application performance:

```javascript
// Custom metrics
const prometheus = require('prom-client');

const httpRequestDuration = new prometheus.Histogram({
  name: 'http_request_duration_seconds',
  help: 'Duration of HTTP requests in seconds',
  buckets: [0.1, 0.5, 1, 2, 5]
});

app.use((req, res, next) => {
  const start = Date.now();
  res.on('finish', () => {
    const duration = (Date.now() - start) / 1000;
    httpRequestDuration.observe(duration);
  });
  next();
});
```

### 3. Log Monitoring

Monitor application logs:

```javascript
// Structured logging
const winston = require('winston');

const logger = winston.createLogger({
  level: 'info',
  format: winston.format.json(),
  transports: [
    new winston.transports.File({ filename: 'error.log', level: 'error' }),
    new winston.transports.File({ filename: 'combined.log' })
  ]
});

logger.info('User logged in', { userId: 123, ip: '192.168.1.1' });
```

## Logging Best Practices

### 1. Structured Logging

```javascript
// ✅ Good: Structured
logger.info({
  event: 'user_login',
  userId: 123,
  timestamp: new Date().toISOString(),
  ip: req.ip
});

// ❌ Bad: Unstructured
logger.info('User 123 logged in from 192.168.1.1');
```

### 2. Log Levels

```javascript
logger.error('Critical error occurred', { error });
logger.warn('Deprecated API used', { endpoint });
logger.info('User action', { action: 'login', userId });
logger.debug('Debug information', { data });
```

### 3. Centralized Logging

```javascript
// Send logs to centralized service
const winston = require('winston');
const { ElasticsearchTransport } = require('winston-elasticsearch');

const esTransport = new ElasticsearchTransport({
  level: 'info',
  clientOpts: {
    node: 'http://localhost:9200'
  }
});

const logger = winston.createLogger({
  transports: [esTransport]
});
```

## Alerting

### Alert Rules

```yaml
# Prometheus alert rules
groups:
  - name: example
    rules:
      - alert: HighErrorRate
        expr: rate(http_requests_total{status=~"5.."}[5m]) > 0.05
        for: 5m
        labels:
          severity: critical
        annotations:
          summary: "High error rate detected"
```

### Alertmanager

```yaml
# alertmanager.yml
route:
  receiver: 'slack-notifications'
  routes:
    - match:
        severity: critical
      receiver: 'pagerduty'

receivers:
  - name: 'slack-notifications'
    slack_configs:
      - api_url: 'https://hooks.slack.com/services/...'
        channel: '#alerts'
```

## Best Practices

1. **Monitor Key Metrics**: CPU, memory, disk, network
2. **Set Appropriate Alerts**: Not too noisy, not too quiet
3. **Use Structured Logging**: Easier to query and analyze
4. **Centralize Logs**: Single source of truth
5. **Retention Policies**: Keep logs for appropriate duration
6. **Security**: Don't log sensitive information
7. **Performance**: Logging shouldn't impact performance
